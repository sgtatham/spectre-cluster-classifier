This git repository accompanies the arXiv preprint ["Chasing
rotational symmetry in the spectre
tiling"](https://arxiv.org/abs/2609.07592), which describes a
decomposition of the Spectre tiling into three metatiles called
'diabolo', '2-arms' and '3-arms'.

It contains Rust code to confirm by calculation the claim that _any_
Spectre tiling can be decomposed into these metatiles, using the
transducer system from ["Finite-state transducers for substitution
tilings"](https://arxiv.org/abs/2512.16595), via the Rust library
crate
[`substitution-tiling-transducers`](https://crates.io/crates/substitution-tiling-transducers/).
The problem of checking every tile in an infinite tiling, or worse,
every tile in each of an uncountable number of different infinite
tilings, is reduced to checking each of a finite set of tile address
prefixes.

Also, 'cosmetics files' are provided to take an existing plot of a
Spectre tiling generated by that crate's plotting tool, and re-colour
it to show its decomposition into the three metatiles.

The code is intended to be reusable as a way to check other
decompositions of the Spectre tiling into specified clusters of tiles,
whether or not they are a true system of metatiles. To do that, add a
new main program in `src/bin` alongside the existing one, with
different descriptions of the cluster shapes.
