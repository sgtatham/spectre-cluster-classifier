This git repository accompanies the arXiv preprint ["Chasing
rotational symmetry in the spectre
tiling"](https://arxiv.org/abs/2609.07592), which describes three
clusters of Spectre tiles and states that any tiling of the whole
plane can be decomposed into those clusters.

It contains Rust code to confirm that claim by calculation, using the
transducer system from ["Finite-state transducers for substitution
tilings"](https://arxiv.org/abs/2512.16595), via the Rust library
crate
[`substitution-tiling-transducers`](https://crates.io/crates/substitution-tiling-transducers/).
The problem of checking every tile in an infinite tiling, or worse,
every tile in each of an uncountable number of different infinite
tilings, is reduced to checking each of a finite set of tile address
prefixes.

Also, 'cosmetics files' are provided to take an existing plot of a
Spectre tiling generated by that crate's plotting tool, and re-colour
it to show its decomposition into the clusters described.
